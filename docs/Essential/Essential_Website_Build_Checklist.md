# Essential tier — website build checklist

**Use for:** One-time Essential website projects (not Essential Care ongoing support).  
**Typical price:** $1,450–$1,950 (most land at $1,650–$1,750) · **Timeline:** 2–4 weeks  
**Demo reference (live):** https://mahoneydigital.net/examples/riverside-lawn/ (clean Essential reference for sales calls) · tailored Casto's Auto Repair demo exists locally but left untouched per owner instruction (2026-06-08); use riverside-lawn for Essential positioning until further notice.

---

## Before you start (sale closed)

- [ ] Verbal or written yes on **Essential** scope (home + up to 4 pages, contact form, mobile-first, basic SEO)
- [ ] **Deposit received** (recommend 50% to start — document amount and date in `Clients/<Name>/`)
- [ ] Primary contact name, phone, email confirmed
- [ ] Domain situation noted (they own one / need one / you register on their behalf)
- [ ] Content owner clear (they provide text/photos vs you write placeholders)

---

## Kickoff (week 1)

- [ ] Kickoff call or text: business name, services, service area, hours, how customers should contact them
- [ ] Collect: logo if any, 3–10 photos (optional for Essential), phone, address, email
- [ ] Agree on page list (e.g. Home, Services, About, Contact — ≤4 plus home)
- [ ] Set launch target date
- [ ] Create project folder in `Clients/<BusinessName>/` with notes and assets

---

## Build

- [ ] Mobile-first layout; test on real phone
- [ ] Business name, contact info, and services overview on site
- [ ] Click-to-call and contact form (Netlify or agreed host)
- [ ] Fast load — no heavy galleries, video, or complex embeds (per Vision out-of-scope)
- [ ] Basic on-page SEO: title, meta description, headings, local wording
- [ ] Client preview link shared for feedback

---

## Revisions (included: 30 days after launch)

- [ ] Track edit requests in client folder; stay within Essential scope
- [ ] Batch small text/image swaps; avoid scope creep (new pages, e-commerce, big galleries → change order or Growth)

---

## Launch

- [ ] DNS / domain pointed to hosting (Netlify or agreed)
- [ ] HTTPS working
- [ ] Form submissions tested
- [ ] Google Business Profile: confirm website URL updated (client or you, per agreement)
- [ ] Handoff: how to reach you, what’s included in 30-day edit window
- [ ] Final invoice / balance collected

---

## After launch

- [ ] Offer **Essential Care** (optional) — see `Essential_Care_Process.md` and `docs/Client_Facing/Essential_Care_Client_Overview.md`
- [ ] Do **not** auto-sell Growth; only if they ask for more pages, SEO, or GBP help
- [ ] Ask for testimonial or permission to list as work (when they’re happy)

---

## Out of scope (remind if asked)

Heavy galleries, video, complex maps/calendars, e-commerce, custom apps, ongoing content marketing — see `VISION_AND_SCOPE.md` Essential tier.
