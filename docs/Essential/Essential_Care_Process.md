# Essential Care – Service Delivery Process

**Light-touch, reliable maintenance for Essential website clients.**

## Purpose

Essential Care is designed to be simple, affordable, and low-maintenance for the client while ensuring their website stays secure, fast, and functional. This tier is intentionally limited in scope.

---

## 1. Core Deliverables

As outlined in the Vision document, Essential Care includes:

- Monthly security monitoring, malware scans, and reliable automatic backups
- Core platform and security updates
- Up to **60 minutes of small content or text updates per quarter**
- Basic uptime and performance monitoring with email alerts if something breaks
- Email support with **48-hour target response time**
- One **quarterly status email** summarizing site health and any recommended small actions

This is **reactive and maintenance-focused**, not proactive or strategic.

---

## 2. Monthly Tasks

Perform these tasks every month:

1. **Security & Backup Check**
   - Confirm automatic backups are running successfully
   - Run malware/security scan
   - Verify no critical security updates are pending

2. **Core Updates**
   - Apply platform and plugin/theme security updates (as needed)

3. **Uptime & Performance Monitoring**
   - Check that the site is loading normally
   - Note any significant slowdowns or downtime
   - Set up or maintain basic uptime alerts if not already in place

4. **Review Support Tickets**
   - Respond to any client emails within 48 hours

**Time estimate:** 30–60 minutes per client per month.

---

## 3. Quarterly Tasks

Once per quarter:

1. **Small Updates (up to 60 minutes total)**
   - Make any requested small text/content changes (price updates, new phone number, minor service description tweaks, etc.)
   - Do **not** take on large projects in this tier

2. **Quarterly Status Email**
   - Send a short, professional email that includes:
     - Site health summary (security, backups, uptime)
     - Any updates performed
     - Any issues found
     - 1–2 small recommendations if relevant (keep very light)

**Template available in:** `/docs/Email_Templates/`

---

## 4. Tools & Setup (Essential Tier)

Keep this tier as low-overhead as possible.

Recommended tools:
- Hosting backup system (most hosts include this)
- Security plugin with malware scanning (e.g., Wordfence, Sucuri, or built-in host security)
- Uptime monitoring (free tier of UptimeRobot or similar is usually sufficient)
- Simple email for support

Avoid complex dashboards or expensive tools for Essential clients.

---

## 5. Communication Guidelines

- **Response time:** Within 48 hours (business days)
- **Scope discipline:** Be firm about the 60-minute quarterly limit. If a request will exceed this, politely explain and offer to quote it as a separate project.
- **Tone:** Helpful, efficient, and low-pressure. These clients generally want things to “just work” without much interaction.

---

## 6. Onboarding Essentials

When a new Essential Care client signs up:

1. Confirm hosting and domain access.
2. Set up or verify automatic backups.
3. Install/activate basic security measures.
4. Set up basic uptime monitoring.
5. Add client to your support email system.
6. Send welcome email with what’s included and how to request small updates.

---

## 7. Red Flags & Escalation

Contact the client if you notice:
- Repeated malware infections
- Significant unexplained downtime
- Major security vulnerabilities that require more than basic updates
- Requests that clearly exceed the 60-minute quarterly limit

In these cases, have a conversation about upgrading to Growth Partner or handling the work as a one-time project.

---

## 8. What Essential Care Is NOT

- Not proactive strategy work
- Not regular content creation
- Not major website redesigns or new features
- Not Google Business Profile management
- Not local SEO work
- Not monthly calls or detailed reporting

Keeping clear boundaries is important for profitability and client expectations at this tier.
