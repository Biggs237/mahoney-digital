# Notes.md — what to write after a call or email

Paste this block at the bottom of **`Outreach/<Business>/Notes.md`** under **Conversation log** (newest first).

```markdown
## Conversation log

**YYYY-MM-DD — Call** ((740) 492-8601)
- **Reached:** Owner / employee / voicemail / no answer
- **They said:** _(quote or paraphrase)_
- **I said:** _(demo link sent? follow-up date?)_
- **Outcome:** Interested / Maybe later / Not interested / No contact
- **Next:** _(e.g. Text demo link Jun 6; call back Tue 10am)_

**YYYY-MM-DD — Email** (hello@mahoneydigital.net)
- **To:** address
- **Subject:** _(subject line)_
- **Outcome:** Sent / Bounced / Replied — _(summary)_
- **Next:** _(follow-up date)_
```

Also tick checkboxes at the top of `Notes.md` (First outreach, Reply received, Follow-up).
